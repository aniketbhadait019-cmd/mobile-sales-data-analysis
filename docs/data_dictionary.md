# Data Dictionary

| Column | Description |
|---|---|
| Sr.no | Serial number of the record |
| Sale_ID | Unique sale identifier |
| Year | Year of sale |
| Month | Month number of sale |
| Date | Sale date |
| Brand | Mobile phone brand |
| Model | Mobile phone model |
| City | Customer/sale city |
| State | Customer/sale state |
| Channel | Sales channel such as Online or Offline |
| Price_Segment | Price segment of the mobile |
| Network | Network generation such as 4G/5G |
| Units_Sold | Number of units sold |
| Unit_Price_INR | Unit price in INR |
| Discount_Percent | Discount percentage applied |
| Revenue_INR | Revenue generated in INR |
| Customer_Age | Customer age |
| Customer_Gender | Customer gender |
| Payment_Method | Payment method used |
| Return_Flag | Whether the sale was returned |
| Customer_Rating | Customer rating |
| Age_Group | Derived customer age group |
| Rating_Category | Derived rating category |
| Price_Category | Derived price category |
