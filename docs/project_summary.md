# Project Summary

## Project Type
Data Analysis / Exploratory Data Analysis (EDA)

## Problem Statement
Analyze mobile sales data to understand sales performance, revenue patterns, customer behavior, pricing, discounts, channels and product performance.

## Main Skills Demonstrated

- Data loading and inspection
- Data cleaning
- Missing-value analysis
- Duplicate analysis
- GroupBy and aggregation
- Feature engineering
- Correlation analysis
- Exploratory data analysis
- Data visualization
- Business insight generation

## Main Python Libraries

Pandas, NumPy, Matplotlib and Seaborn.

## Expected Business Questions

- Which brands generate higher revenue?
- Which channels contribute to sales?
- How do discounts relate to revenue?
- Which cities/states have stronger sales?
- Which price segments sell more units?
- What customer age groups are most represented?
- How are customer ratings distributed?
- What payment methods are commonly used?
- What is the return pattern across products/channels?
